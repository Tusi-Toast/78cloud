
> 所有样式和脚本均内联在 `index.html` 中，无外部依赖，便于部署和修改。

## 🚀 如何使用

### 本地运行
直接在浏览器中打开 `index.html` 文件即可。

### 部署建议
- 上传至任意静态托管服务（如 GitHub Pages、Vercel、Netlify、七牛云等）
- 或放入 Nginx/Apache 的 Web 目录

### 修改内容
- **文字信息**：直接编辑 HTML 相应文本
- **链接地址**：替换 `a` 标签的 `href` 属性
- **QQ群/客服链接**：更新 `https://qm.qq.com/q/...` 链接
- **主题色调**：修改 `:root` 与 `.light-theme` 中的 CSS 变量

## 🎨 主题切换说明

- **默认模式**：跟随系统 `prefers-color-scheme`
- **手动切换**：点击右上角按钮（🌙/☀️）
- **持久化**：使用 `localStorage` 保存用户选择
- **适用范围**：背景、文字、边框、按钮等主要元素

## 📱 响应式断点

| 设备           | 宽度范围      | 主要优化                     |

## ⚙️ 维护与自定义

### 更新联系方式
1. 找到 `contact-section` 区域
2. 修改 QQ 群、QQ频道、客服号码及对应的加群链接
3. 更新页脚中的客服信息

### 修改推广文案
- 价格说明：`.price-info` 内的 `.price-details`
- 重要提示：`.notice` 块
- 合作推广：第二个 `.price-info` 块

### 调整样式
- **全局变量**：`html` 字体基准、`:root` / `.light-theme` 中的颜色变量
- **组件样式**：直接修改对应类名的 CSS 规则

## 🔒 安全与兼容

- 所有外部链接均添加 `rel="noopener noreferrer"`
- 移动端防止双击缩放（保留一部分可访问性）
- 打印样式优化，避免背景和渐变导致的墨水浪费
- 支持现代浏览器（Chrome, Edge, Firefox, Safari），IE 不支持
